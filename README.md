# Patience

Eine kleine Sammlung von Patiencen für das iPad. Gebaut als Webseite, die sich zum
Home-Bildschirm hinzufügen lässt und danach wie eine App startet — im Vollbild und
ohne Internet.

Enthalten sind: 10×10, Katzenschwanz, Spider, Onkel Max, Opa 1, Opa 2, 10×4,
Halbes Taschentuch und Gitter.

Kein Konto, keine Werbung, keine Datenübertragung. Der Spielstand bleibt auf dem Gerät.
